# 图寻助手（Tuxun Helper）使用教程

> 本教程随 exe 打包发行，面向直接下载 exe 的用户。GitHub 上的 README 是开发者向文档；
> 你正在看的这份才是「拿到 exe 怎么用」的说明。
> 仓库地址：https://github.com/HighPing64x/tuxun-helper

---

## 一、这是什么

图寻助手是一个**本地运行**的游戏辅助工具，支持两个平台：

- **图寻**（tuxun.fun）：每日挑战 / 积分赛
- **GeoGuessr**（geoguessr.com）：每日挑战 / 经典地图

它通过两种方式帮你获得实时位置信息：

| 模式 | 原理 | 需要装证书？ | 需要改系统代理？ |
|------|------|:---:|:---:|
| **镜像模式（推荐）** | 本地反向代理，你访问 `127.0.0.1:8001` 就等于访问 tuxun | 否 | 否 |
| **拦截模式** | 系统代理 MITM，解析街景元数据 | 是（首次） | 是 |

**新手直接用镜像模式即可**——不需要装证书、不需要碰系统代理，用完关掉就干净了。

## 二、快速开始（3 步）

1. **双击 `TuxunHelper-Realtime.exe`**，会打开一个控制台窗口。
   - 如果弹出「端口被占用」询问：说明你之前开过一个实例，选 `1` 退出先关旧窗口，或选 `2` 自动结束旧进程。
2. **浏览器自动打开选择页**（深色分屏页面）。没自动开就手动访问 `http://127.0.0.1:18080/`。
   - 中间白点是菜单：**悬停白点**展开圆环（贡献者 / 退出 / GitHub）。
   - **左侧点「图寻」** → 进入图寻镜像做题；**右侧点「GeoGuessr」** → 进入 GeoGuessr 镜像。
3. **在镜像页面里正常登录/做题**。第一次访问时工具会请求你的登录态：
   - 已在 `.env` 配好 Cookie 的直接可用；
   - 未配置的：在官方站登录后，工具检测到 Cookie 会弹询问「是否自动录入」，点是即可，之后免配置。

做完题关掉 exe 窗口即可，什么都不会残留（镜像模式完全不动系统设置）。

## 三、游戏页面悬浮窗

进入对局后，页面左下角会出现「📍 图寻助手」悬浮窗：

- **原点**：本回合出题点（真值，金色）。回合结束时自动显示**答案**。
- **目前**：你的实时位置（可移动回合），括号内为距出题点距离。
- **诱饵 / 候选**：反诱饵统计。图寻会在街景元数据里注入假坐标（诱饵），
  工具自动识别并排除；无法立即判定的归入「候选」等待 API 校准。
- **⚙ 设置**：所有功能开关都收在这里（详见下节）。
- **复制原点**：把当前真值坐标复制到剪贴板。
- **隐藏面板**：只留一个小 📍 图标，随时点回。

## 四、设置项说明（⚙ 设置）

| 设置 | 默认 | 说明 |
|------|------|------|
| 防诱饵 | 开 | 自动排除街景元数据里的假坐标 |
| 判定距离 | 150 米 | 距真值多少米内视为同一地点（不算诱饵） |
| 显示延迟 | 0.4 秒 | 捕获到坐标后的延迟显示，缓解"瞬间跳图" |
| API直读 | 关 | 直接轮询官方接口拿真实坐标（最准，绕过一切街景层诱饵） |
| AI自动 | 关 | 需在 `.env` 配 AI Key；新回合自动抓图分析并自动对答案 |
| 名称保护 | 关 | 只改页面上显示的你的昵称/ID，不动网络数据 |
| **一键特定分数** | 关 | 见下节 |

## 五、一键特定分数（热键落点）

"一键 5000"的进阶版：**你想要几分就几分**。

1. ⚙ 设置 →「一键特定分数」→ 勾选**启用**；
2. 填**目标分数**（例如 3500）；
3. 点**热键**输入框，按下你想用的键（默认 `F9`）；
4. 进入对局，想提交时**按热键**——工具按计分模型
   `分数 = 5000 × e^(-10×距离/地图尺寸)` 反推出对应距离，随机方位落点并通过
   游戏自己的 ws 通道提交（和手点地图完全同构，不产生异常请求）。

注意：
- 地图尺寸自动判断（中国图 ≈6120km / 世界图 ≈14916km），也可在 config.json `map_size` 手工指定校准；
- 分数是模型估计，实际得分可能有 ±几十分偏差，多试几轮即可摸准；
- 需要**真值已捕获**（原点显示不为 `-`）才可用；
- 仅图寻镜像页面生效。

## 六、后台与日志

- **TUI 后台**（推荐）：命令行运行 `TuxunHelper-Realtime.exe --tui`，
  一个实时仪表盘显示端口状态 / 捕获状态 / 日志尾部。`Ctrl+C` 退出。
- 日志文件在 `logs/` 目录，**所有 Cookie / 票据都会被自动脱敏**，可以放心发给别人排查。
- 网页右下「退出」或直接关窗口，都会自动还原系统代理（仅拦截模式受影响）。

## 七、常见问题

**Q: 提示「端口被占用」？**
A: 你开了两个实例。弹窗里选 `2` 会自动结束旧进程；或自己去任务管理器结束旧的 `TuxunHelper`。

**Q: 镜像页面白屏 / 打不开？**
A: 看控制台日志。极少数情况是上游 CDN 抖动，刷新或重启 exe 即可。

**Q: 一键分数没反应？**
A: 三个条件：① 设置里勾了启用；② 原点已捕获（悬浮窗原点不是 `-`）；③ 已进入对局（ws 已连接）。悬浮窗底部会提示原因。

**Q: 会被封号吗？**
A: 工具全程只读不改游戏请求，提交走游戏原生通道，且默认所有主动型功能（API直读/AI自动/一键分数/名称保护）都是**关闭**的，由你自行决定是否开启。请自行评估风险、理性使用。

**Q: 想自定义端口？**
A: `config.json`：`mirror_port`（图寻，默认 8001）、`mirror_port_geo`（Geo，默认 8002）、`control_port`（选择页，默认 18080）、`proxy_port`（拦截，默认 8080）。
