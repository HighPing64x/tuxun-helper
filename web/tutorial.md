# 图寻助手 v2.0 使用教程

> 本教程随 exe 打包发行。**v2.0 是全网页版**：本地只运行一个后台程序，
> 所有操作——选择平台、登录、做题辅助、地图、设置——全部在浏览器网页里完成。

## 一、这是什么

图寻助手是一个**本地运行**的游戏辅助工具，支持两个平台：

- **图寻**（tuxun.fun）：每日挑战 / 积分赛
- **GeoGuessr**（geoguessr.com）：每日挑战 / 经典地图

v2.0 架构：

- **后台**：一个控制台程序（`TuxunHelper-Realtime.exe`），负责代理/镜像/捕获；
- **网页前端**：浏览器访问 `http://127.0.0.1:18080/`，所有功能都在这里；
- **登录**：选择平台后可访问平台官网并自动拦截 Cookie，也可直接手动输入 Cookie。

## 二、快速开始（2 步）

1. **双击 `TuxunHelper-Realtime.exe`**。会打开一个后台控制台窗口（这是服务，别关），
   浏览器随后自动打开网页控制台。
   - 如果弹出「端口被占用」询问：说明你之前开过一个实例，选 `1` 退出先关旧窗口，或选 `2` 自动结束旧进程。
2. **在网页里完成一切**：
   - **首页**：左图寻 / 右 GeoGuessr，点击直接进入对应镜像做题；
     中间白点悬停展开圆环（贡献者 / 退出 / GitHub）。
   - **登录**：点底部 Dock 的「登录」或首页平台 → 选平台 → 「访问官网并自动拦截」或「手动输入 Cookie」。
   - **仪表盘**：原点/目前/答案实时状态、诱饵/候选统计、最近捕获列表。
   - **地图**：所有捕获点落图（OSM 瓦片经本地代理加载），点击列表坐标可直接定位。
   - **设置**：全部功能开关都在网页里调（防诱饵/API直读/AI自动/一键特定分数/名称保护/瓦片源…）。

做完题关掉后台窗口即可（或在网页首页白点圆环里点「退出」），不残留任何系统设置。

## 三、镜像 vs 拦截

| 模式 | 原理 | 需要装证书？ | 需要改系统代理？ |
|------|------|:---:|:---:|
| **镜像模式（默认）** | 本地反向代理，访问 `127.0.0.1:8001/8002` 就等于访问平台 | 否 | 否 |
| **拦截模式（进阶）** | 系统代理 MITM，解析街景元数据，配合官方站使用 | 是 | 是 |

日常使用只碰镜像模式即可。拦截模式可在网页「设置」页开关（需先 `--install-cert` 装证书）。

## 四、游戏页面悬浮窗

进入对局后，镜像页面左下角出现「📍 图寻助手」悬浮窗：

- **原点**：本回合出题点真值（金色）；回合结束自动显示**答案**（蓝色）。
- **目前**：你的实时位置（可移动回合），括号内为距出题点距离。
- **诱饵 / 候选**：反诱饵统计；工具自动排除假坐标，存疑的归入候选等待 API 校准。
- **⚙ 设置**：悬浮窗内也能快速调常用开关（与网页设置页同步）。
- **一键特定分数**：⚙ 设置里启用后，游戏中按热键（默认 F9）即按目标分数（默认 3500）
  自动落点提交——走游戏原生 ws 通道，与手点地图同构。

## 五、后台 CLI

后台窗口本身就是一个可用的 CLI：

```
TuxunHelper-Realtime.exe            # 后台服务 + 自动打开网页（默认）
TuxunHelper-Realtime.exe --tui     # TUI 仪表盘（端口/捕获状态/日志尾部），Ctrl+C 退出
TuxunHelper-Realtime.exe --login tuxun     # 浏览器打开图寻官网并自动拦截 Cookie
TuxunHelper-Realtime.exe --no-mirror       # 本次不开镜像
TuxunHelper-Realtime.exe --install-cert    # 装拦截模式证书（用拦截模式才需要）
```

日志在 `logs/` 目录，Cookie/Key 全部自动脱敏，可放心分享排查。

## 六、常见问题

**Q: 提示「端口被占用」？**
A: 多开了实例。弹窗选 `2` 自动结束旧进程，或去任务管理器手动结束旧的。

**Q: 登录后状态还是「未登录」？**
A: 确认使用的是官网自动拦截或手动输入方式；自动方式需要本地代理已开启，手动方式需粘贴包含 `fun_ticket=` 或 `session=` 的 Cookie。

**Q: 一键分数没反应？**
A: 三个条件：设置里启用；原点已捕获（不为 —）；已进入对局。悬浮窗底部有原因提示。

**Q: 网页地图不显示？**
A: 默认 OSM 瓦片经本地代理（合规 UA + 缓存）加载；如网络仍慢，可在设置里换高德/卫星瓦片。

**Q: 会被封号吗？**
A: 工具全程只读不改游戏请求，主动型功能（API直读/AI自动/一键分数/名称保护）默认关闭，由你自行决定是否开启。请自行评估风险、理性使用。
